# Real-Time Auction Platform 🔨

![Status](https://img.shields.io/badge/Status-In%20Development-orange)

Projeto desenvolvido para a Unidade Curricular de Laboratórios de Sistemas e Serviços (LSS) - Universidade de Aveiro. Uma plataforma de leilões concorrente e em tempo real suportada por WebSockets e Redis.

## 👥 A Equipa
* **Henrique Gala** - Backend API & PostgreSQL (Data Layer)
* **Arthur Spanó** - Concorrência, WebSockets & Redis Pub/Sub
* **Lorenzo Lima** - Frontend UI & Integração DevOps

## 🏗️ Stack Tecnológica
* **Backend:** FastAPI (Python)
* **Real-Time:** WebSockets & Redis
* **Base de Dados:** PostgreSQL
* **Infraestrutura:** Docker & Docker Compose
